# Tanishqa Trivedi — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript. The hero section features a conceptual DNA-to-computational-analysis-to-research-insight map; it is an educational illustration, not a deployed model or clinical tool.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

No build tools or frameworks are required. Google Fonts are loaded from Google Fonts when an internet connection is available.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation, scroll progress and reveal effects
